# 📄 Ask Your PDF

**Ask Your PDF** is a Streamlit-based app that lets you upload PDF documents and interact with them using natural language questions. It uses Google's Gemini AI to generate context-aware responses based on the content of your uploaded files.

## 🚀 Features

- Upload and process multiple PDF files
- Extract text and split into manageable chunks
- Generate semantic embeddings using Google Generative AI
- Store embeddings in a FAISS vector database
- Retrieve relevant information using similarity search
- Ask questions and get accurate, contextual answers

## 🛠️ Tech Stack

- Python
- Streamlit
- PyPDF2
- LangChain
- Google Generative AI (Gemini)
- FAISS
